# 直播数据复盘台

作者：[@Bella-rab](https://github.com/Bella-rab) · [MIT License](LICENSE)

**在线使用（免安装，打开即用）**：<https://bella-rab.github.io/live-review-desk/>

一个**纯前端、零依赖**的直播运营复盘工具：把每场直播的指标录进来，自动跟自己的历史比、
跟品类基准比，最后给出「该继续推进还是该纠偏」的裁决。

> 解决的问题：每天看后台数据，看的时候有感觉，第二天就忘了；跨天跨场比不出来，
> 也说不清「到底比出了什么、差距在哪、接下来该优化还是继续往下走」。

## 能做什么

8 个页面，分析页下再拆 19 个维度板块（子页签，点着看，不用一路往下滚鼠标）：

| 页面 | 板块 |
|---|---|
| 导入数据 | 粘贴表格文本 / 上传 CSV·TXT / 载入示例 |
| 场次库 | 历史场次管理、改、删、导出备份、导入备份 |
| 单场诊断 | 总览 / 转化漏斗 / 流量与时段 / 商品表现 / 问题诊断 / 行动清单 |
| 场次对比 | 差距概览 / 指标明细 / 走势对比 / 结论与决策 |
| 主播对比 | 效率排行 / 能力诊断 |
| 趋势看板 | 走势图 / 趋势解读 / 指标明细 |
| 问题库 | 问题追踪 / 整改建议 |
| 行动清单 | 待办清单 / 分工与验证 |

核心能力：

- **决策裁决分四档**：继续推进 / 保持节奏（样本不足时诚实说「先积累」）/ 定向优化 / 立即纠偏，
  优先序是「硬伤 > 趋势」，样本少于 3 场不硬编结论
- **指标基准比对**：内置 6 大品类基准，未知品类自动回落到「通用」，不会白屏
- **跨场趋势**：每场指标斜率、停留↔转化弹性、指标间相关性（找出真正的抓手）
- **行动清单**：诊断命中的问题自动拆成待办，可勾选、可指派责任人，刷新和切场次都还在
- **保存不是「假成功」**：写入后回读校验，不一致即判定失败并在顶栏显示三态指示

## 快速开始

**方式零（最省事）**：直接在线用 → <https://bella-rab.github.io/live-review-desk/>

不用下载、不用安装，点开就有界面。缺点只有一个：数据存在**你当前这个浏览器**里，
换设备、换浏览器或清理站点数据会丢 —— 重要数据记得用「导出备份」，别只留在浏览器里。

**方式一（本机使用，可离线）**：双击 `index.html`。没有构建步骤，没有服务器要求。
需要 `index.html`、`engine.js`、`store.js` 三个文件放在同一个文件夹里 —— 按
`Code → Download ZIP` 整包下载后解压，直接就是这个结构。

**方式二（自己部署）**：把这个目录部署到任意静态托管（GitHub Pages / Vercel / 对象存储均可）。

> ⚠️ **在 GitHub 网页上点 `index.html`，看到的是源码，不是网站。** GitHub 是代码仓库，
> 默认只把文件当文本展示，不会替你运行页面 —— 这跟项目写得对不对无关。
> 想用 GitHub 免费得到一个别人也能打开的网址，要额外开启 Pages：
> 仓库 `Settings` → `Pages` → Source 选 `Deploy from a branch` →
> 分支 `main` + 目录 `/ (root)` → `Save`，约一分钟后访问
> `https://<用户名>.github.io/<仓库名>/`。
> 只在本地自己用的话，按方式一双击即可，不必开 Pages。

上手路径：打开后点「载入示例历史」灌 6 场，立刻能看到对比、趋势与裁决；
熟悉之后再把自己的真实数据「粘贴」进来。

## 数据存在哪（重要）

**所有数据只存在你自己浏览器的 localStorage 里，不上传任何服务器 —— 本项目没有后端。**

- 键名：`fupantai.sessions.v3`（场次）、`fupantai.todos.v1`（行动清单）
- 因此：**换设备、换浏览器、清站点数据都会丢** → 请定期用「导出备份」存成 JSON 文件
- 无痕/隐私模式下浏览器会拒绝写入，页面顶部会出现红色警示（此时先导出再继续录入）

## 项目结构

```
index.html    单页应用本体（视图、交互、样式全部内联）
engine.js     分析引擎：品类基准表、诊断规则、决策裁决、待办派生
store.js      持久化仓库：localStorage 后端、写入回读校验、导入导出
test-*.js     测试套件（13 套，见下）
```

三个文件、零依赖、零构建、无 CDN。

## 测试

全部零依赖，直接 `node` 跑，退出码 0/1：

```bash
# 桩环境（不需要浏览器）
node test-engine.js    # 分析引擎规则
node test-store.js     # 持久化仓库
node test-multi.js     # 多场次集成
node test-render.js    # 渲染冒烟
node test-tabs.js      # 维度板块
node test-e2e.js       # 端到端
node test-decide.js    # 决策裁决
node test-journey.js   # 5 天连续录入的完整旅程
node test-nav.js       # 返回键与导航

# 真实无头 Chrome（需要本机装了 Chrome）
node test-lib.js       # 场次库操作：6 种视口 + 真实坐标点击
node test-todos.js     # 行动清单跨会话持久化（两次独立进程）
node test-browser.js   # 完整用户路径
node test-online.js    # 发布后验证线上版本（可选，需先部署）
```

真机测试的 Chrome 路径写在脚本顶部的 `CHROME` 常量里，非 Windows 或装在别处请自行修改。

`test-online.js` 默认指向作者部署的线上地址，请用 `node test-online.js <你的地址>` 或改顶部常量。

## 技术说明

- **零依赖**：没有框架、没有构建、没有 CDN，就三个文件
- **一次只渲染当前板块**，而不是全量渲染后用 CSS 隐藏 —— 隐藏容器的 `clientHeight` 为 0，
  会让 Canvas 图表画不出来
- **持久化必须校验**：`createLocalBackend` 会「探测 → 写入 → 回读」三步走，回读不一致就判定失败，
  避免隐私模式/配额满时 UI 显示「已保存」而数据其实没落盘
- **导航历史栈 + hash 路由**：支持顶栏返回键、浏览器后退、刷新后停在原页；窄屏下侧栏隐藏时
  由顶栏换页菜单兜底

## 自定义品类基准

`engine.js` 顶部的 `BENCHMARKS` 是 6 个品类的经验基准值
（服饰 / 食品 / 美妆 / 家居 / 日用 / 通用），换成你自己行业的基准即可。

注意保留「通用」这一项，未知品类会回落到它。
